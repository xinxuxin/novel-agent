# Reference Repositories

This directory stores reconnaissance material for WenForge Studio.

- `repos/` contains shallow local clones of third-party repositories used for static analysis only.
- `repos/` is intentionally ignored by Git so third-party source is not vendored into this project.
- Do not copy source code from these repositories into WenForge Studio during the reconnaissance phase.
- Do not install dependencies or run scripts from these repositories unless a later task explicitly approves it.
